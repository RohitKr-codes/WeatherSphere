# ☁️ WeatherSphere 🌍

> A modern, cinematic, and responsive real-time weather application built using HTML, CSS, and JavaScript with OpenWeather API integration.

---

## ✨ Features

- 🌤 Real-time weather updates
- 🔍 Search weather by city name
- 🌎 Dynamic cinematic backgrounds
- 🏙 City-specific HD backgrounds
- 🌧 Weather-based background effects
- 🔐 Login & Register authentication system
- 💎 Modern Glassmorphism UI
- ⚡ Fast and responsive performance
- 📱 Mobile-friendly design
- 🎨 Smooth animations & transitions
- 🌈 Interactive hover effects
- 🌙 Professional dark aesthetic

# ⚙️ Installation
## 1️⃣ Clone Repository
```
git clone https://github.com/RohitKr-codes/WeatherSphere.git
```

## 2️⃣ Open Project
```
Open the folder in VS Code.
```

## 3️⃣ Add Your API Key
```
Inside script.js
const API_KEY = "YOUR_API_KEY";
Get your free API key from:
OpenWeather API
```
## 4️⃣ Run Project
```
Open:
login.html
using Live Server.
```
